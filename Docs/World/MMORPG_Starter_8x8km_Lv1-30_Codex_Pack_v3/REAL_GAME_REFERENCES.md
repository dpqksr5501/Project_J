# 실제 게임 스크린샷 레퍼런스 — 개별 원본 링크

**사용 방식:** 이 문서의 `R01~R09`는 **실제 출시된 게임의 스크린샷 링크**이다. 이미지는 직접 저장할 수 있도록 별도의 원본 페이지/이미지 URL을 제공한다. 게임의 정확한 월드·에셋·디자인을 복제하지 않고 **배치 원리**만 분석한다. `R10`은 개별 스크린샷을 추가로 찾아볼 수 있는 공식 포토갤러리다.

이미지들을 한 장의 인포그래픽으로 합치지 않는다. 각 이미지의 건축 규모, 길, 지형 경사, 수변·수목 밀도 등 목표 요소를 각각 분석한다. 외부 파일을 로컬 프로젝트에 무단으로 복사하거나 상업용 에셋처럼 사용하지 않는다.

## 참고 시 유의사항
- 스크린샷은 건물 에셋 다운로드 링크가 아니다.
- 일부 커뮤니티 촬영본은 후처리/모드/그래픽 프리셋의 영향을 받을 수 있다.
- 외부 URL에 Codex가 접근하지 못하면 해당 이미지가 로컬로 저장된 폴더를 사용자에게 요청한다.
- 실제 색·재질을 그대로 모방하는 것이 아니라 도시 구조, 도로 폭, 필지의 불규칙성, 지형과 정착지의 연결성을 참고한다.
