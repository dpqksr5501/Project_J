# 에셋과 콘텐츠의 남은 판단

2026-10-17 초기 조사 기준. 아래는 구매 목록이 아니며 기존 자산 검증을 먼저 한다.

- 건축: MedCastle의 성문·탑·교량과 기존 팩을 함께 놓고 실제 스케일·재질·texel density·지붕/기초 접합·문/실내·충돌을 확인한다. MedievalVillage의 파손 모듈과 원경 전용 자산은 생활 마을의 완제품과 구분한다.
- 자연: 침엽수·활엽수·덤불·초지·암벽은 보유한다. 근/중/원경 실루엣, alpha/WPO/VSM, 수종 간 색·축척, 메모리와 충돌 비용은 대표 구간에서 비교해야 한다.
- 수계: 초기 표면은 검토용이다. 최종 강둑·퇴적·급류·포말·폭포·해안 접합 및 수영/부력/항해 채택 범위가 남아 있다. Water Body가 지형 수문학 전체를 해결한다고 가정하지 않는다.
- 날씨: 기존 시간/강우 상태와 태양·안개 기반 외에 구름·비/눈·실내 강수 차단·젖음/적설·바람·환경 음향을 실제 자산으로 연결해야 한다. 외부 날씨 플러그인 구매를 선행 조건으로 삼지 않는다.
- 전투: H01–H09의 최종 군집·Nav/Leash·혼잡·안전 경계와 B01/B02 모델·리깅·애니메이션·스킬·텔레그래프 적합도는 미확정이다. 기존 테스트 NPC를 최종 보스라고 표시하지 않는다.
- 생활/탐험: 도시·농지·마을의 NPC·채집·퀘스트·상점·보상·음향·실내 콘텐츠가 필요하다. 배치 수를 플레이 밀도와 동일시하지 않는다.
- 5.7 Elderboom 원본은 보존했다. 대상 5.8에서 선택 모듈·활엽수·소품을 실제 로드·배치했다. 새 Megascans 라이브러리는 누락 의존성 39개를 기록했고 해당 참조가 전이되는 메시를 제외한다. 팩 전체를 품질 합격으로 취급하지 않는다.

S00의 첫 구도는 주택/작업장 8채·광장·우물·농지·울타리·수목과 S01 성문 진입부까지 저장됐다. 건물 간 스타일 통일, 창/문·실내·기초의 최종 조형, 숲 하층과 원경 수목, 자연스러운 물가와 거시 산체 아트는 여전히 다듬어야 한다. 배치 개수는 AAA 품질 승인이나 플레이 콘텐츠 구현을 뜻하지 않는다. 날씨 후속 작업은 사용자 결정으로 보류한다.

경제·레벨 스탯·드롭률·PvP·보스 영속 일정은 이번 구조 제작에서 독단적으로 확정하지 않는다.
