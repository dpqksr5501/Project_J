# 전체 감사 인계의 보관과 현재 기준

2026-10-14 인계 본문은 후속 소스·BP·DA 정리와 main 통합 이전의 기록이다. 2026-10-15 사용자 요청에 따라 필요한 이력은 보관하고, 이 경로는 현재 기준을 찾는 안내로 통합했다. 과거 전체 감사·성능 요청을 자동 재개하지 않는다.

- [현재 통합 기준과 유지·보류 범위](../../Review/README.md): main 통합, R19/R20, 현재 결정과 단계별 검증 기록.
- [프로젝트 맥락](../../Overview/ProjectContext.md)과 [애니메이션 기준](../../Animation/README.md): 실제 구조·제작·보존 계약.
- [Mirror Data 도입 보류](../../Animation/Planning/Mirror_Data_Adoption_Decision_2026-10-15.md): 현재 locomotion을 유지하고 특정 연결 문제가 확인될 때만 재검토한다.
