# 8×8km 월드 공간 구성 — 진행 중

목표 원천은 [v4 실행 지시서](../World/Project_J_8x8km_WorldGen_Completion_Expansion_v4.md)와 [탑뷰 참고 이미지](../World/초반%20지역%208×8km%20판타지%20월드맵.png)다. 이 문서는 실제 구현한 공간과 남은 연결 작업을 구분한다. 전체 Phase 1 완료나 출시 합격 문서가 아니다.

## 공간·좌표 기준

`MainWorld.manifest.json`의 남서 원점·동/북 미터 좌표를 Unreal 중앙 원점 센티미터로 변환한다. 현재 높이장은 8,064m 사각형/2m 표본이며, 기존 산체와 -76.5~1,400.75m 범위를 유지한다. 참고 이미지의 600~800m 표기는 현재 산을 낮추는 지시로 사용하지 않는다. 원본 높이를 평탄화하지 않고 자연 집터와 개별 기초·계단·교량으로 고도 차를 처리한다.

실제 ID·경계·레벨 원천은 `MainWorld.plan.json`/Native DA이며, v4 역할 대응은 `MainWorld.locations.json`과 [대응표](01_EXISTING_TO_TARGET_MAPPING.csv)가 소유한다. 지명이나 숫자를 일괄 바꿔 기존 게임플레이 참조를 끊지 않는다. S07 강변은 새 안정 S07로 등록했고 Native 장소는 19개다. S09 관문=새 안정 S08의 등록은 아직 남아 있다.

## 현재 연결과 수계

기존 plan의 장거리 도로와 에디터의 RouteCandidates는 경사/교량/통행 미검증 후보를 포함한다. S00/S01의 실제 접근부와 석교, 새 마을의 지역 길·입구를 전역 도로 완료로 확대 해석하지 않는다. 호반→산악의 6.14km 우회 조사안도 최종 도로로 채택하지 않았다. 실제 교량 세 종류·산길·전망대·퇴각로와 전역 연결 검증은 Phase 2 이후 남아 있다.

S04는 기존 안정 S03의 (1650,5700)m 마을 중심을 보존한다. 물은 145m이고 마을 중심은 약 160.56m이다. 자연 호안으로 내려가는 길에서 (1650,5580)m 호안 접속부를 거쳐, 약 5.42% 경사 진입판과 상면 146.25m의 T자 선착장으로 이어진다. 부두 끝은 (1650,5518)m이며 기존 190m 장소 경계 안이다. 실제 마을길→선착장 네 지점 이동과 저장본 collision을 확인했다. 임시 물의 외관/충돌·수영·물길 연속성은 아직 합격하지 않았다.

기존 하천/호수/해안 표면은 Phase 2에서 산지 수원→지류→본류→호수/평야→하구의 흐름과 단면을 다시 확인해야 한다. 후보 spline과 불투명 표면을 최종 자연 수계로 취급하지 않는다. 월드 경계의 도로/수계/바이옴 연장은 기존 edge contract를 소비해 별도 인접 Region에서 검증할 예정이다.

현재 수량과 검증 범위는 [구현 상태](03_IMPLEMENTATION_STATUS.md), 실제 소유 Actor/입력 지문은 `MainWorld.generation.json`, 확장 구조의 한계는 [아키텍처](05_WORLD_ARCHITECTURE.md)를 따른다.

S05는 안정 S06의 (6600,1250)m 장소/190m 경계 안에서 하구를 활용했다. 본류 옆 약 120m 부두와 높은 창고/주거 둔덕을 연결하고 감시탑을 보존된 자연 집터에 배치했다. 육상 진입판은 약 12.37%이며 부두 가장자리로 연결해 데크 안쪽 겹침을 제거했다. 북쪽 접근과 부두 연결은 실제 보행으로 확인했지만, 항만의 연속 수심/운항·해안 표현과 전역 도로/탈것은 별도 후속이다.

S06는 안정 S05의 기존 580.75m 중심/190m 경계를 유지하고 서쪽 골짜기에 개별 기초로 주택을 배치했다. 주택 바닥 약 484.72~531.86m, 전망 데크 539.95m다. 지역 산길 중심선은 1m 표본의 20% 경사 제한으로 탐색했으며 서쪽 진입부터 전망대까지 실제 보행했다. 북쪽 길 전체·전역 접속·원시 격자 코너 곡선화·폭/탈것 검증은 남아 있다. 원본 산을 평탄화하지 않았다.

S07 강변 취락은 (4900,2670)m/170m의 새 안정 장소다. 기존 장소와 사냥터 예약 영역을 피해 하류 강둑에 8동을 배치하고, 본류를 가로지르는 약 110m 목교와 양측 진입판으로 강둑을 연결했다. 기존 석교와 다른 목재 도하 형상이 추가됐지만 교량 3종/전역 도로/탈것 통과 완료를 뜻하지 않는다. Native 기존 18개 장소는 그대로이며, 새 S07 한 곳만 append했다.

S09=안정 S08은 북부 능선 (3440,8030)m/150m 논리 반경과 레벨 안으로 제한한 사각 경계에 배치했다. E_N_Road는 동일 ID로 (3352,8064,891.3125)m에 옮겼으며, 캠프 내 국소 접근로만 보행 확인했다. 남쪽 지역 도로/헤어핀은 급경사 검토 후보로 남긴다.

S08=기존 S00 길목 초소는 시작 마을 북동부의 수도 방향 도로를 감시한다. 망루 (3160,3220)m/전망층32.107m, 병영 (3130,3214)m, 노점 (3185,3188)m이며 검문 중심은 (3158,3180)m이다. 기존 8채와 시작점/Source place는 유지했다.

H01은 안정 중심(3200,2700)m의 경계를 보존하며 남쪽43m 공터·서쪽 낮은 공터14.875m·남서 오목지14.4375m로 전투 군집을 분산한다. 마을 방향(3100,2892)m과 서쪽(2920,2800)m을 안전 길로 잇고 군집에는 별도 분기로 들어간다. 스폰/리셋 후보는 안전 길에서20m 이상 이격해 저작했으며 활성 AI 검증은 후속이다.

H02 (ridge_stockade_and_beast_hollow)은 기존 장소 경계 안의 전투 군집 H02.G01, H02.G02과 별도 안전 길/진출입을 갖는다. 구릉/저지대 고도 차를 유지하고 주요 농지와 군집을 분리했다. 실제 영역/경로/목책/구조물 위치의 원천은 Manifest의 hunting_profiles다.

H03은 서쪽(5260,3880)m에서 북쪽(5510,4140)m으로 기존 숲 가장자리를 통과하고 세 군집으로 분기한다. 실제 줄기 충돌을 피하는 수관 아래 길과 기존 엄폐 나무6곳을 활용하며, R_East 수변을 별도 제외해 불필요한 도하를 만들지 않았다. 실제 군집/숲길/엄폐 참조의 원천은 Manifest의 hunting_profiles다.

H04는 기존 장소 경계 안의 육상 공터 H04.G01~G03과 서→동 통과길/분기·퇴각을 갖는다. 원본 자연 경사를 유지하며 타원형 임시 물 메시 밖에 공터와 길을 이격했다. 현재 물 가장자리는 지면과 만나지 않아 눈높이에서 검은 측면/떠 있는 수면이 보인다. 육상 첫 배치만 확인했으며 자연 호안/습윤 전이·수계 완성은 아니다. Phase 2에서 고정 수면145m·기존 호반 부두와의 연결/자연 지형을 함께 검토해 수정해야 한다. 전체 평탄화나 거대한 임시 둑으로 가리지 않는다. 실제 공간/경로와 물 제외 계약은 Manifest의 hunting_profiles가 원천이다.

H05는 고도163.44/216.88/233.25m의 벌목·유적·상부 공터를 기존 숲 마을과 분리해 저작했다. 서쪽 진입에서 북쪽으로 우회하는 등고선 길과 군집 분기를 연결하고 H05 예약 코어에만 수목260개를 보강했다. 고도 차를 유지했으며 원시 경로의 굴곡/폭·지피·수로와 유적 규모는 후속 환경/도로 작업이다. 실제 전투 후보·트레일·수목 인스턴스의 원천은 Manifest의 hunting_profiles다.

H06는 원래 경계 안의 자연 저지대2곳을 약19.25/20.25m 수면으로 채우고, 남쪽23.875m·북쪽26.1875m·상부32.5m의 전투 공터와 별도 육상 통과길을 연결했다. 수면은 원본 지면과 만나는 등고선으로 자르고 물가 지피1000개를 보강했다. 흐르는 얕은 수로/큰 강 연결과 최종 습지·물 표현은 후속이다. Native 물·지피 제외의 기하는 사냥터 프로필이 참조하는 MainWorld.H06.wetland.json이 원천이다.

H07 안정 ID는 유지하며 내륙 기획 후보에서 실제 남동 해안(7500,850,40.5625)m로 보정했다. 반경340m와 경계 형상은 평행 이동했다. 실제 지형/공간을 우선하는 v4 좌표 수정 규칙을 적용했다. 원래 후보의 바다와 연결되지 않은 작은 음수 고도 웅덩이를 해안으로 오인하지 않았다. 해안 수면 기반은 남쪽 전역으로 연결했고 절벽·야영·안전 대체 길은 다음 저작이다.

H07은 낮은 동/서 해안 공터(17.375/14.5m)와 상부 능선 공터43.25m를 연결하고, 암벽 위험 원을 피하는 내륙 우회로를 확보했다. 실제 물과 떨어진 동쪽 공터에 천막2/밀수품을 배치했다. 원본 높이는 유지했으며 암벽 소유 메시에서23.31m 실제 낙차를 측정했다. 초기 배치/우회 보행이며 최종 해안 절벽군/야영 생활·AI/낙하 피해 기능 완료는 아니다. 단일 Source는 Manifest의 hunting_profiles다.

H08 (mountain_mine_forecourt_and_hollow_gallery)은 기존 장소 경계 안의 전투 군집 H08.Forecourt, H08.InnerChamber과 별도 안전 길/진출입을 갖는다. 구릉/저지대 고도 차를 유지하고 주요 농지와 군집을 분리했다. 실제 영역/경로/목책/구조물 위치의 원천은 Manifest의 hunting_profiles다.

H08은 높은 원본 산을 유지하며(2300,5950)m 능선의 광산과 남동 비탈의223m 돌계단·능선길을 연결했다. 작업 터(2320,5936)m와 갱실 내부를 구분하고 바깥 진입/퇴각 및 Source 스폰 후보를 통합했다. 산길→굴 끝→작업장 연속 보행을 확인했으며, 낮은 계단참과 지역 대도로의 모든 지면 진입/탈것 경로는 Phase 2에서 별도로 완성해야 한다. 단순 외피/옹벽/계단 아트·광산 생활/기능은 후속이다.

H09 (tiered_ruins_on_natural_shelves_with_western_bypass)은 기존 장소 경계 안의 전투 군집 H09.Court, H09.Shrine, H09.Grove과 별도 안전 길/진출입을 갖는다. 구릉/저지대 고도 차를 유지하고 주요 농지와 군집을 분리했다. 실제 영역/경로/목책/구조물 위치의 원천은 Manifest의 hunting_profiles다.

Road_Forest_Plateau와의 물리적 연결은 Phase2 후속이며 Source의 계획 도로가 후보 리셋 원에서 떨어져 있다는 검사만으로 연결 완료를 주장하지 않는다.
