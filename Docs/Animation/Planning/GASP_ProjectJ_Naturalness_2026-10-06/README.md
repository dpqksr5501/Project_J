# GASP / Project_J 움직임 자연스러움 분석과 고도화 인계

기준일: 2026-10-06. 상태: **조사 결과 보존 및 후속 설계 제안**. 구현 완료 문서가 아니다.

## 먼저 읽을 결론

이 조사의 목표는 **Project_J의 전체 애니메이션 자연스러움 개선**이다. 입력과 실제 이동, trajectory, 후보 데이터와 검색 안정성, Idle/Start/이동/Stop 및 점프/낙하/착지 연결, 몸과 루트의 회전, 발 접지, 원격·군중 예산을 함께 다룬다. 약 180도 반전은 급격한 입력에서도 이 연결이 유지되는지 확인하는 여러 검증 항목 중 하나다.

GASP는 조건에 따라 검색 후보를 구성하고, 선택한 클립의 현재 시점에 맞춘 보정과 시각 루트 처리, 마지막 발 접지를 연결한다. Project_J에도 trajectory, 풍부한 Cycle 데이터, 단발 수명 관리와 발 접지가 있으며 보존할 가치가 있다. 단일 PSD 선행 선택, 일반 MM 내부 보정 경로, 외부 단발 출력 계약과 데이터 설정의 차이가 어떤 상황에 영향을 주는지는 전체 움직임 baseline과 실제 출력으로 판단한다. 큰 Turn의 감속 중 수명과 긴 낙하 출력은 그 과정에서 확인할 구체적인 이슈이지 전체 개선 목표를 대신하지 않는다.

이는 **확인된 구조에서 도출한 설명**이다. 새 영상 비교로 자연스러움의 인과관계를 입증한 결론은 아니다.

## 사용자의 목적과 보존 조건

- 최상위 목적은 전체 움직임의 입력 반응, 자세·발걸음 연속성, 동작 연결과 접지 품질을 높이는 것이다. 180도 전환에만 작업 범위를 한정하지 않는다.
- Idle↔Start↔이동↔Stop, Walk/Run/Sprint 가감속, 작은 곡선 이동, 점프↔낙하↔착지, 동작 중 입력·카메라 변경을 함께 평가한다.
- 일반 이동·이동 Turn은 PSD/MM으로, Start·Stop·Land·Strafe Pivot·TIP 등은 State Controller·Chooser·외부 Blend Stack으로 처리하는 기존 구조를 존중한다.
- 작은 회전에서 이미 자연스러운 Cycle 선택을 제거하지 않는다. 각도별 Turn을 강제하지 않는다.
- Strafe 키보드 반전은 기존 Pivot을 유지한다.
- OTM 키보드 약 180도, OTM/Strafe 마우스 기반 몸과 경로의 큰 반전, 170/190도·연속 반전은 전체 평가의 스트레스 시나리오로 포함한다.
- 몸만 회전하는 경우와 세계 이동 경로까지 반전되는 경우를 구분한다.
- MMORPG의 로컬·원격·군중 예산, 전투·몽타주·탑승·리타깃 계약을 함께 고려한다.
- GASP가 항상 우수하다고 가정하지 않는다. Project_J의 입력 반응, 단발 수명, 예산과 선택 소유권은 보존 가치가 있다.

## 작업 권한과 현재 상태

원래 분석은 소스·설정·에셋 수정/저장/컴파일을 금지했다. 사용자는 이 대화에서 Unreal MCP와 computer-use를 명시적으로 허용했고, 실제 에셋 조회에 사용했다. **문서 작성 요청으로 Markdown·PDF·근거 추출물 저장만 새로 허용되었으며, 코드·Config·에셋·레벨 변경 권한은 확대되지 않았다.**

이 문서 작성에서도 에셋·레벨 저장, Blueprint 컴파일, UBT 빌드, 새 PIE 검증은 수행하지 않는다. 이전 대화의 MCP 허용을 새 대화의 자동 허용으로 해석하지 않는다. 후속 작업은 프로젝트 AGENTS.md와 사용자의 해당 작업 권한을 먼저 확인한다.

## 증거 표기

- **G**: 실제 그래프·핀·내부 함수·바인딩 확인.
- **A**: 실제 에셋 속성·Chooser 조건/출력·PSD/PSS 설정 확인.
- **S**: 현재 로컬 프로젝트/설치 엔진 소스 확인.
- **H**: 기존 PIE 로그·문서·사용자 확인의 역사적 증거.
- **D**: 문서에만 기록된 설명. 현재 활성 구현의 증거로 단독 사용하지 않는다.
- **I**: 확인된 사실에서 도출한 해석·설계 제안.
- **U**: 미확인. 무엇을 확인해야 하는지 함께 기록한다.

각 문서의 G/A/S는 조사 시점 기준이다. 파일명·노드 존재·참조 목록만으로 G를 부여하지 않는다. G와 A가 있어도 실제 화면 품질이나 성능 실측을 의미하지 않는다.
