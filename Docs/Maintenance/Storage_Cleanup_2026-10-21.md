# 저장 공간 정리와 현재 문서 갱신 — 2026-10-21

## 정리한 범위

플레이어 로코모션 전환 후 저장 공간을 점검했다. 작업 전 논리 집계는 `Saved` 약 42.687GiB, 현재 `Content` 약 61.035GiB, `Intermediate` 약 11.108GiB였다. Git/LFS 이력과 월드 제작 자료도 크지만, 이름·나이·크기만으로 불필요하다고 판정하지 않았다.

두 임시 실험 프로젝트의 `Content`에서 현재 프로젝트 또는 별도 기준 샘플의 같은 상대 경로·크기·SHA-256과 일치하는 사본만 제거했다. 실험 프로젝트는 `Saved/GASP58Migration_20261019/Experiments` 아래의 격리 자료이며 현재 프로젝트의 실행·제작 진입점이 아니다. 각 제거 경로의 절대 위치가 이 두 실험 Content 루트 안인지 검증하고, 제거 직전에 사본과 보존 원본을 모두 다시 해시 비교했다. 재귀 폴더 삭제를 사용하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 동일 사본 제거 | 7,162개 / 9,006,579,677 bytes, 약 **8.39GiB** |
| 고유한 실험 에셋 | 2,673개 / 약 2.70GiB 보존 |
| 현재 Content·변환/원본 모션·골격·프로필 | 이번 정리에서 삭제·재임포트·명칭 변경 없음 |
| 현재 빌드·PDB·Intermediate·DDC | 보존. 증분 빌드 상태를 무효화하는 일괄 캐시 정리 없음 |
| Git/LFS·월드 제작/복구·개인 저장/설정 | 보존. 과거/현재 원자료의 자동 일괄 삭제 없음 |
| 이전 단계 백업·실패 자료·최종 회귀 결과 | 보존. 이번 작업의 사용 여부를 판정하지 못한 자료는 삭제하지 않음 |

위 용량은 삭제 파일의 논리 합계다. 삭제 전 드라이브 여유 공간을 같은 조건으로 측정하지 않았으므로 실제 디스크 회수량과 동일한 관측값이라고 주장하지 않는다. 과거 정리에서 확보한 공간을 이번 합계에 더하지 않았다.

제거 후 보존 원본 7,162개를 다시 SHA-256으로 읽어 명세와 일치함을 확인했고, 현재 Content 파일 수도 전후 15,886개로 같았다. 논리 합계·보존 범위·로컬 명세의 지문은 [정리 요약 JSON](Storage_Cleanup_2026-10-21.json)에 남겼다.

실험 사본은 이제 완전한 독립 프로젝트 백업이 아니다. 다시 구성하려면 로컬 명세의 counterpart/해시를 기준으로 보존 원본에서 누락 파일을 복사해야 한다. 고유 에셋과 Source/Config·실험 메타데이터는 유지한다. 로컬 상세 명세·제거 journal·검증은 `Saved/StorageCleanup_20261021`에 있으며, Git으로 옮기지 않는 외부 기준 샘플의 현재 위치도 그 명세에만 기록한다.

## 문서의 현재 기준

포트폴리오와 제작 진입점은 [플레이어 로코모션 아키텍처](../Animation/Architecture/Player_Locomotion_Architecture.md)로 정리했다. Mover·C++ 상태/핀 계산·ABP 평가 시점·공용 모션·몸체별 보정의 실제 책임을 설명한다. 외부 샘플/모션/엔진 노드의 출처와 프로젝트에서 통합한 범위를 별도 절에 명시했다. 샘플을 자체 제작한 것처럼 바꾸지 않았다.

기존 이관 문서는 [플레이어 로코모션 전환·검증 기록](../Animation/Architecture/Player_Locomotion_Migration_2026-10-19.md)으로 이동하고 옛 경로는 안내로 남겼다. 실제 runtime 에셋·코드·Saved 경로의 이름은 문서 표현 정리와 함께 변경하지 않았다. README·프로젝트 개요/맥락·애니메이션/제작/이동 목차·확장·골격/IK·전투·원격 이벤트의 현재 설명을 갱신했다. R19/R20·CMC/MM·과거 성능과 현재 구조를 구분한다.

전체 문서의 로컬 링크와 현재/과거 진입점을 검사했다. 작업 전 74개 오류 중 5개는 검사기가 URL 인코딩된 한글·공백 경로를 해석하지 못한 경우였고, 1개는 루트 README의 퇴역한 궤적 소스 링크였다. 나머지 68개는 당시 Source/Scripts 경로를 텍스트로 보존하고 현재 안내를 연결했다. 과거 기록의 실패·측정값·원본 비교는 삭제하거나 새 구조의 통과 결과로 바꾸지 않았다. 전체 문서의 모든 API·설계·수치를 새 runtime에서 재검증한 것으로 확대하지 않는다.

현재 정의와 대조하다 발견한 소모품 제작 설명도 실제 `UProject_JConsumableDefinition`과 사용 요청/소유자 재검증 경로로 수정했다. UI의 이전 CMC SavedMove 수정은 현재 Mover 입력 승인과 구분했다. 단순 이름 검색만으로 제안·제거 이력을 현행 API 오류로 처리하지 않았다.

큰 안내/제작 본문을 갱신하기 전 작업 사본 10개는 [원문 ZIP](../Archive/Navigation/2026-10-21/Before_Current_Documentation.zip)과 [SHA-256 명세](../Archive/Navigation/2026-10-21/Preservation.json)로 보존했다. 전체 목록은 기존 생성기로 재생성하며, 링크 검사와 `git diff --check`를 수행한다. 저장소 밖의 선택적 Worktrees 증거 12개는 현재 없는 로컬 자료로 구분하며 가짜 파일이나 근거를 만들지 않는다.

카탈로그 생성기가 기존 World/WorldGen 및 새 주제의 문서를 목록에서 누락할 수 있던 부분도 수정했다. 문서 시작점·월드 주제를 포함하고, 새 주제도 기본 항목으로 표시한다. 바뀐 현재 가이드로 향하는 절 앵커와 보존 ZIP의 해시도 별도로 확인한다.

이번 변경은 문서·문서 검사기·동일 임시 사본 정리다. runtime 코드/에셋 변경이 없어 Unreal 빌드·PIE를 다시 실행하지 않았다. 이전 IK 작업의 61개 native/실제 플레이 결과를 새 실행으로 보고하지 않는다. 정리 시작 시 관련 editor/build/game 프로세스가 없었고, 이번 작업에서 에디터를 열지 않았다.
