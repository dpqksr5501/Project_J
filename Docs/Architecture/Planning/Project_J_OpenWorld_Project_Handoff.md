## 두 인계에서 추가로 확인한 계약

- **전투와 호환성.** 몽타주 경고는 AttackDefinition의 정책·진입 섹션과 실제 Notify를 대조한다. 콤보 비용은 첫 유효 노드에서 서버가 한 번 확정한다. Ground Pulse는 별도의 지면 공격으로 서버 마나와 재사용 대기를 확인했다. ASC·Avatar 교체와 사망·취소 시 이전 경고가 철거된다. 실시간 프로토콜은 16이며 이전 15 접속의 거절을 시험했다. 서버와 클라이언트는 대응 버전을 함께 배포한다. [기반의 제작 계약](Project_J_OpenWorld_Foundation_Handoff_2026-11-26.md#새-콘텐츠를-연결하는-방법) · [후속 구현](Project_J_OpenWorld_Sol_Implementation.md#후속-구현에서-달라진-계약)
- **군중과 지연.** CanonicalNetwork의 16접속 기준선은 렌더 관찰자 한 대와 경량 15개였고, 별도의 40접속 시험에서는 경량 연결을 사용했다. 제작 MainWorld B01의 독립 2접속과 단독 PIE의 보상 우편은 각각 다른 실행이다. Iris의 면제·한도 제외 집계 단위는 연결–객체 쌍이다. 로컬 경량 클라이언트를 60FPS로 제한한 비교에서 지연이 달라졌으며, 실전 피해 표시의 꼬리 지연은 같은 공격의 승인·송신·수신·표시 시각을 맞춰야 원인을 판단할 수 있다. [소켓·렌더·보상 검증 기록](Project_J_OpenWorld_Sol_Implementation.md#후속-구현에서-달라진-계약)
- **제작 누락과 지역 이동.** 잘못된 포털이 정상 던전 등록을 덮거나 다른 월드에서 나온 투사체가 현재 전투에 섞이던 경우를 재현해 수정했다. 선택 검사는 HUD 입력·저장 ID, NPC 추격 한계와 원형 기술의 실제 부여 경로도 다룬다. 지역 왕복은 실제 게임 서버에서, 배치 키 이관은 닫힌 SQLite 복사본에서 검증했다. 출시 데이터 이관, 재접속 위치, 운영 드레인과 저속망은 각 배포 조건에서 확인한다. [독립 검증과 원자료](Project_J_OpenWorld_Astra_Independent_Review_Handoff_2026-11-26.md)

## 다음 사람이 어디서 검증을 시작하는가

- **제작 중에는 변경 대상을 먼저 검사한다.** BP·DA는 에디터의 Validate Assets, 원경 액터는 열린 맵에서 Validate, 새 야외 지역은 저장 맵 검사부터 시작한다. 누락된 필수 연결 한 건과 의도적으로 제외한 정상 사례를 함께 써야 과도한 검사도 발견한다. 마지막 집중 회귀는 66건 중 일반 통과 65건·경고 동반 통과 1건, 선택 에셋 15/15였다. PoseSearch의 후속 3/3은 별도 실행이다. [검사별 범위와 로그](Project_J_OpenWorld_Astra_Independent_Review_Handoff_2026-11-26.md#빌드와-재실행-결과)
- **한 PC에서 이어갈 일**은 최종 변경분의 새 Cook·Stage와 일반 입구 재시험, 대표 바이옴의 연속 주행 히치 분석이다. 기존 패키지 두 실행의 이동 직후 합계 360프레임에서 최대 28.51ms였고, 에디터의 초지 연속 이동에는 최대 87.43ms 간격이 남았다. 같은 경로·카메라·프리셋의 냉간/재방문을 나눠 I/O, 컴포넌트 등록, PSO, 렌더/GPU와 메모리를 맞춰 본다. 지연 원인은 미확정이다. [실행 조건과 순서](Project_J_OpenWorld_Astra_Independent_Review_Handoff_2026-11-26.md)
- **추가 환경에서 인수할 일**은 제작 MainWorld의 독립 16·40인 밀집 교전, 최소 사양 장시간 주행·시각 품질, 실제 회선·분리 호스트 운영이다. 현재 PC에서는 제작 맵 메모리 사전 검사에서 다인 시험을 보류했다. 40은 경량 연결로 확인한 규모이고 제품의 최대 인원은 미정이다. 로컬에서 렌더 클라이언트 하나와 부하 생성기를 쓰면 서버와 관찰자 비용을 분리할 수 있다. [성능 자료](../../Performance/README.md)
